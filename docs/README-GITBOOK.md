# GitBook Upload Notes

This folder is ready to use as a GitBook docs source.

- `README.md` is the landing page.
- `SUMMARY.md` defines navigation.
- `.gitbook.yaml` points GitBook to the summary and landing page.
- Product pages describe the **full Knix idea**.
- `reference/feature-status.md` makes the launch boundary explicit: **The Pool is functional; other DApp modules are display only unless actually implemented.**

Before publishing production addresses, rates, TVL, token information, or feature status, replace specification language only with verified live data.
