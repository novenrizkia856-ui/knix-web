# KNIX Token

**Launch status: Display / Concept only.**

The full Knix idea can include a native **KNIX** protocol token used for protocol coordination rather than as a requirement for using The Pool.

## Potential roles

KNIX may eventually support:

- staking;
- governance participation;
- protocol incentive programs;
- ecosystem alignment;
- access to community mechanisms.

## Not required for Pool launch

Pool deposits and withdrawals should not depend on a token that does not yet exist.

These docs intentionally define **no token address, supply, allocation, mint policy, vesting schedule, or market value**. Those are separate launch decisions that require explicit specification before deployment.

## UI rule

The website can show KNIX as part of the full product concept. The DApp must not display fake wallet balances, price, market cap, APR, or contract addresses.
