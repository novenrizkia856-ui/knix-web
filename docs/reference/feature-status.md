## Required labels

Use clear status labels:

- **Live** — backed by an actual deployed and verified transaction path;
- **Read-only** — backed by actual state reads but does not transact;
- **Display Only** — part of the product concept but not functional;
- **Concept** — documented direction without finalized implementation.

A polished screen is not sufficient reason to label a feature live.
