# Glossary

## AMM
Automated Market Maker. Onchain infrastructure that allows swaps against pooled liquidity.

## Dual-earning
The Knix concept of allowing a single pool position to capture value from vault yield and trading fees when the connected infrastructure supports both.

## ERC-4626
A standard interface for tokenized vaults that represent shares of deposited assets.

## KNIX
A conceptual Knix protocol token. No production token is claimed by these docs.

## LP
Liquidity Provider. A user or contract that supplies assets to a trading market.

## Pool share
An accounting unit representing proportional ownership of a Knix Pool.

## Registry
A conceptual canonical index of recognized Knix Pools and configuration metadata.

## Slippage protection
Transaction bounds that reject execution if the result is worse than a user's accepted minimum or maximum.

## Stable leg
The stable or quote-asset side of a configured Pool, potentially eligible for the vault layer.

## The Pool
The only module intended to be transactionally functional in the first Knix DApp release.

## Tokenized asset
An EVM token representing or referencing an external financial asset or economic claim, subject to its issuer and contract design.

## Vault
A third-party or protocol contract that accepts assets and issues shares representing a claim on managed assets.

## Display Only
A product module included in website or DApp navigation to communicate the full product direction but not yet backed by executable contracts.
